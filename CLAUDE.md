# Рудик — заметки для работы в этом репозитории

Голосовой ассистент Инженерной академии РУДН. Два независимых приложения:
`backend/` (Python, uv) и `frontend/` (React, TanStack Start).

## Команды

```bash
# бэкенд (из backend/)
uv sync --extra rag --extra voice   # rag = fastembed, voice = GigaAM + Vosk + Silero
uv run rudik-serve                  # API на 127.0.0.1:8000
uv run rudik-scrape --cache --index # пересобрать данные из кэша HTML
uv run rudik-index                  # только индекс
uv run python scripts/bench_stt.py  # WER распознавания на типичных вопросах
uv run python scripts/check_stream.py  # прогон записи через голосовой канал

# фронтенд (из frontend/)
npm run dev      # 3000, /api проксируется на 8000
npm run lint
npm run build
```

## Что где лежит

| Путь | Ответственность |
|---|---|
| `backend/src/backend/scraper/` | обход сайта: `crawl` (BFS), `parsers` (типы страниц), `pipeline` (сборка документов) |
| `backend/src/backend/rag/` | `documents` (нарезка), `index` (BM25 + векторы + RRF), `store` (синглтон), `build` (CLI) |
| `backend/src/backend/agent/` | `tools` (инструменты), `graph` (LangGraph), `prompts` |
| `backend/src/backend/voice/` | `asr` (GigaAM в ONNX), `hotword` (Vosk на потоке), `session` (машина состояний канала), `tts` (Silero локально, Piper и edge запасными), `speechtext` (нормализация текста перед синтезом), `wakeword` (нечёткое сравнение) |
| `backend/src/backend/api/` | роутеры FastAPI |
| `frontend/src/lib/` | `api.ts` (клиент), `rudik-store.ts` (состояния экрана) |
| `frontend/src/hooks/useVoiceStream.ts` | микрофон, AudioWorklet, вебсокет с сервером |
| `frontend/public/rudik-capture.js` | AudioWorklet: кадры моно PCM16 16 кГц |
| `frontend/src/components/rudik/` | киоск: сцена с позами, шапка и подвал, панель состояния |

## Правила, о которых легко забыть

- **Модель self-hosted**: Qwen на vLLM через `ChatOpenAI` с `base_url`. Ключа
  нет, но библиотека требует непустую строку — отсюда `RUDIK_LLM_API_KEY=EMPTY`.
- **Рассуждения Qwen выключены** (`RUDIK_LLM_THINKING=false`): модель тратила на
  них полторы-пять секунд, а первый чанк с текстом приходил только после. Флаг
  уходит в vLLM как `chat_template_kwargs.enable_thinking`.
- **Плата за выключенные рассуждения — промпт**: без них модель на неочевидных
  формулировках («а какой у вас адрес?») переставала звать инструмент и
  придумывала факты. Поэтому в промпте стоит жёсткое «сначала инструмент,
  потом ответ» и разобраны формулировки про адрес. Меняя промпт, проверяйте
  вызовы инструментов, а не только текст ответа.
- **Qwen иногда отдаёт `<think>…</think>` прямо в ответе** — `clean_answer`
  в `agent/graph.py` это вырезает, а `ThinkFilter` делает то же на потоке.
- **К модели ходим мимо системного прокси** — `HTTP_PROXY` в окружении
  заворачивает туда и запросы к vLLM во внутренней сети, а прокси отвечает 502.
  Поэтому `build_model` отдаёт свои httpx-клиенты с `trust_env=False`
  (`RUDIK_LLM_TRUST_ENV=true` вернёт прежнее поведение).
- **Сервер модели может лечь или думать долго** — `answer` и `stream_answer`
  бросают `AgentUnavailable` с готовым текстом для зала, а не трассировку.
  Потолок на весь ответ — `RUDIK_AGENT_TIMEOUT` (45 секунд).
- **User-Agent должен быть ASCII** — httpx кодирует заголовки в latin-1.
- **Ссылки со страницы собираются до `html.clean()`** — чистка выкидывает
  шапку с навигацией.
- **`<header>` внутри карточки сотрудника (`.uk-comment-header`) удалять
  нельзя** — там имя. Чистится только шапка сайта.
- **Тексты и комментарии в коде — на русском**, как и весь интерфейс.
- **Голосовые зависимости опциональны**: код должен деградировать до текста
  и браузерного синтеза, а не падать.
- **`uv run` без `--extra` вычищает опциональные пакеты** — окружение
  пересобирается по базовым зависимостям, и `vosk` с `fastembed` исчезают,
  а киоск молча перестаёт слышать обращение. Всегда
  `uv run --extra rag --extra voice`.
- **Синтез речи локальный (Silero v4, голос eugene)** — фраза озвучивается за
  0.1 секунды. Запасные: `RUDIK_TTS_BACKEND=piper` (легче, без torch) и `edge`
  (облако Microsoft, время ответа от полусекунды до двадцати). Локальные движки
  отдают WAV, edge — mp3, поэтому формат берётся из `tts.media_type()`.
- **torch берём CPU-сборкой** — через `[tool.uv.sources]` в `pyproject.toml`.
  Обычный torch тянет несколько гигабайт CUDA, которые при синтезе на
  процессоре не нужны. Для `RUDIK_SILERO_CUDA=true` индекс меняют на cu124.
- **Синтез надо греть, и не одной фразой** — torch раскачивает графы под каждый
  новый вид входа, поэтому `tts.warmup` прогоняет набор с разными концовками
  предложений. Без прогрева первая реплика стоит двух секунд вместо 0.1.
  Прогрев уходит в фон при открытии голосового канала.
- **Текст нормализуется до синтеза** (`voice/speechtext.py`): «РУДН» → «Рудэн»,
  числа словами, даты в нужном падеже. Правила общие для всех движков —
  синтезаторы читают сырой текст буквально, а некоторые падают на цифрах.
- **Ответ идёт на экран потоком, озвучка — по фразам**: первое предложение
  уходит на синтез, не дожидаясь конца генерации. Порядок кусков держит
  очередь и на сервере, и в браузере — иначе фразы наложатся.
- **Рудика можно перебить голосом**: микрофон не глушится во время озвучки.
  Браузер замолкает по событию `wake`, а не по `interrupt`, и это важно:
  сервер отдаёт всю озвучку за доли секунды и сразу уходит слушать, а браузер
  проигрывает её ещё секунды. Обращение в этот момент приходит уже в обычном
  режиме, `interrupt` не отправляется — замолкать надо всё равно.
  `interrupt` остаётся для перехвата, пока ответ ещё генерируется; ради него
  ответ уходит отдельной задачей (`_run_answer`), иначе `feed` не принимал бы
  кадры. Две опоры, без которых перехват сломается: эхоподавление браузера
  (`echoCancellation` в `getUserMedia`) и запрет в промпте называть своё имя —
  иначе Рудик перебьёт сам себя словом «Рудик» из колонок.
- **Ответы короткие намеренно**: пока Рудик говорит, следующий вопрос ждёт.
  Секунда озвучки — примерно 17 знаков, поэтому промпт требует одно-два
  предложения, а `max_tokens` держится маленьким.
- **Вердикту Vosk о конце фразы не верим сразу** — он закрывает реплику через
  треть секунды тишины, а человек делает паузы длиннее, подбирая слово
  («Рудик, где находится… кабинет Салтыковой»). Ждём подтверждения тишиной
  (`RUDIK_STREAM_ENDPOINT_HOLD_MS`) и склеиваем сегменты. Определять конец
  фразы одной громкостью нельзя: она не отличает паузу от точки.
- **Локальные синтезаторы недетерминированы**: один и тот же текст каждый раз
  звучит немного иначе. Для замеров и тестов wake word нужна записанная
  эталонная реплика, иначе Vosk слышит то «ротик», то «дротик».
- **Две модели распознавания, и это намеренно**: Vosk слушает поток постоянно
  и ловит обращение, GigaAM включается только на выделенную реплику. Гонять
  GigaAM на весь поток нельзя — вырастет задержка.
- **Распознавание блокирующее** — вызывать только через `asyncio.to_thread`,
  иначе встанет весь событийный цикл.
- **Экран — киоск по макету**, а не чат: одно состояние на весь холст.
  Состояния перечислены в `Screen` (`lib/rudik-store.ts`), проверять их удобно
  через `/?screen=<состояние>`.
- **Микрофон требует https или localhost** и жеста пользователя. Сертификат
  для доступа по сети Vite подхватывает из `frontend/certs/`.

## Данные

Карточка «Адрес Инженерной академии» (`page:academy-address`) собирается в
`build_documents` из самого частого адреса в собранных страницах: на сайте
адрес разбросан по карточкам сотрудников, отдельной записи нет, и на вопрос
«где находится академия» поиск возвращал чей-то профиль, а модель придумывала
улицу. Константу не вписываем — переезд подхватится пересборкой.

`backend/data/models/` не коммитится: модели скачиваются сами при первом
запуске (Vosk — `hotword.download_model`, Piper и Silero — `tts.download_model`).
Полгигабайта в репозитории не нужны, а Silero v5 в 139 МБ вообще крупнее лимита
GitHub на файл.

`backend/data/raw/` и `data/index/` тоже не коммитятся. Если индекс пуст, `/api/health` покажет
`chunks: 0`, а поиск вернёт пустоту — нужно запустить скрапер.
