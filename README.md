# Рудик — голосовой AI-помощник Инженерной академии РУДН

Ассистент отвечает голосом и текстом на вопросы об Инженерной академии РУДН,
опираясь только на данные официального сайта [academy.rudn.ru](https://academy.rudn.ru/).

```
Голосом:  «Рудик, скажи где кабинет Салтыковой?»
Голосом:  «Кабинет Салтыковой Ольги Александровны находится в здании
           Инженерной академии, кабинеты 204 и 404.»
           // https://academy.rudn.ru/academy/administration
```

## Как это устроено

```
             речь                    текст запроса
браузер ──────────────► FastAPI ──────────────────► LangGraph-агент (Claude)
   ▲   MediaRecorder    faster-whisper                    │
   │   + VAD            + поиск слова «Рудик»             │ инструменты
   │                                                       ▼
   └───────────── mp3 ◄── edge-tts ◄── ответ ◄── гибридный поиск (BM25 + векторы)
                                                           ▲
                                            data/documents.jsonl ◄── скрапер сайта
```

| Слой | Технологии |
|---|---|
| Бэкенд | Python 3.12, uv, FastAPI, LangChain, LangGraph, Claude API |
| Голос | faster-whisper (локально), edge-tts, детектор обращения «Рудик» |
| Поиск | BM25 (rank-bm25) + плотные векторы (fastembed, multilingual MiniLM), слияние RRF |
| Данные | Свой скрапер academy.rudn.ru на httpx + selectolax |
| Фронтенд | React 19, TanStack Start / Router / Query / Store, shadcn/ui, Tailwind |

## Быстрый старт

### 1. Бэкенд

```bash
cd backend
cp .env.example .env   # и вписать ANTHROPIC_API_KEY
uv sync --extra rag --extra voice
```

Собрать базу знаний (обход сайта ~5 минут, дальше страницы берутся из кэша):

```bash
uv run rudik-scrape --index
```

Запустить API:

```bash
uv run rudik-serve
```

Доступно на `http://127.0.0.1:8000`, документация — `/docs`.

### 2. Фронтенд

```bash
cd frontend
npm install
npm run dev
```

Интерфейс на `http://localhost:3000`, запросы к `/api` проксируются на бэкенд.

## Доступ по сети и микрофон

Vite слушает все интерфейсы, так что страница сразу открывается по адресу
машины — например `http://10.0.0.5:3000`. Бэкенд наружу выставлять не нужно:
запросы к `/api` проксирует сам Vite, поэтому он может остаться на
`127.0.0.1`.

**`VITE_RUDIK_API` при этом должна быть пустой.** Фронтенд ходит на `/api`
своего же origin, и прокси делает всё остальное. Абсолютный адрес ломает
доступ по сети: `localhost` на телефоне — это сам телефон, а http-адрес со
страницы по https браузер просто заблокирует. Обе ситуации фронтенд
распознаёт, пишет предупреждение в консоль и возвращается к своему origin.
Прямой доступ к API нужен, только если бэкенд поднят отдельно: тогда
`RUDIK_HOST=0.0.0.0` в `backend/.env` плюс адрес фронтенда в
`RUDIK_CORS_ORIGINS`.

**Но микрофон по `http://<айпи>` не заработает.** Браузеры отдают
`getUserMedia` только в защищённом контексте: https или `localhost`. По
обычному http страница откроется и текстовый чат будет работать, а на попытку
включить микрофон Рудик честно скажет, что нужен https.

Три рабочих варианта:

**1. HTTPS с локальным сертификатом (рекомендуется для демо в аудитории).**
Сгенерировать самоподписанный сертификат на свой адрес:

```bash
openssl req -x509 -newkey rsa:2048 -nodes -sha256 -days 365 -keyout certs/dev-key.pem -out certs/dev.pem -subj "/CN=rudik-dev" -addext "subjectAltName=IP:10.0.0.5,DNS:localhost"
```

Дальше ничего настраивать не нужно: Vite сам находит `certs/dev.pem` и
`certs/dev-key.pem` и поднимается на https. Пути переопределяются переменными
`RUDIK_TLS_CERT` и `RUDIK_TLS_KEY`, а чтобы вернуться на http — удалите папку
`certs`.

Браузер один раз предупредит о недоверенном сертификате — это ожидаемо. Чтобы
предупреждения не было (и чтобы заработало в Safari на iPhone), используйте
[mkcert](https://github.com/FiloSottile/mkcert): он ставит локальный корневой
сертификат в систему.

**2. Разрешить один адрес в Chrome.** Открыть
`chrome://flags/#unsafely-treat-insecure-origin-as-secure`, вписать
`http://10.0.0.5:3000`, включить и перезапустить браузер. Настраивается на
каждом устройстве отдельно.

**3. Туннель.** `cloudflared tunnel --url http://localhost:3000` или ngrok
дают настоящий https-адрес, который работает на любом телефоне без возни с
сертификатами.

## Голосовой режим

* **Нажми и говори** — кнопка или пробел. Обращаться по имени не нужно.
* **Всегда слушаю** — переключатель в интерфейсе. Браузер сам определяет
  границы фразы по громкости, отправляет фрагмент на бэкенд, а Рудик отвечает
  только если услышал своё имя. Имя ищется нечётко, поэтому «Рудек» и «Рудик»
  из расшифровки одинаково срабатывают.
* Пока Рудик говорит, микрофон на паузе — он не реагирует на собственный голос.

Голос настраивается в `backend/.env`:

```env
RUDIK_STT_MODEL=small          # tiny | base | small | medium | large-v3
RUDIK_TTS_VOICE=ru-RU-DmitryNeural   # или ru-RU-SvetlanaNeural
RUDIK_WAKE_WORD=рудик
```

Если пакеты голоса не установлены, интерфейс не ломается: распознавание
отключается, а ответ озвучивается встроенным в браузер синтезом речи.

### Качество распознавания русского

Замер на 16 синтезированных репликах с фамилиями сотрудников и названиями
кафедр (`uv run python scripts/bench_stt.py small`, CPU, int8):

| Модель | WER | Без единой ошибки | Время на фразу |
|---|---|---|---|
| `small`, общая подсказка | 8.1 % | 9/16 | 3.1 с |
| `small` + словарь академии | 3.5 % | 12/16 | 2.5 с |
| `medium`, общая подсказка | 2.8 % | 13/16 | 7.0 с |

Словарь предметной области (`voice/stt.py`, `domain_prompt`) собирается из базы
знаний — фамилии дирекции и заведующих кафедрами, названия кафедр — и
передаётся Whisper как `initial_prompt`. Это убирает почти все ошибки в
фамилиях и даёт качество уровня `medium` втрое быстрее.

Остаточные ошибки — падежи и редкие слова — до ответа не доходят: поиск по
сотрудникам сравнивает основы слов и склеивает разорванные распознаванием
фамилии, поэтому «Солтыковой», «Кательникова» и «Дмитри Ченкова» находят
нужного человека.

## Скрапер

```bash
uv run rudik-scrape                 # полный обход сайта
uv run rudik-scrape --cache         # пересобрать из сохранённого HTML
uv run rudik-scrape --index         # обход + пересборка индекса
uv run rudik-index                  # только индекс
```

Обход стартует с разделов главного меню сайта и идёт вглубь по внутренним
ссылкам. Результат:

| Файл | Что внутри |
|---|---|
| `backend/data/raw/*.html` | кэш страниц, чтобы не дёргать сайт лишний раз |
| `backend/data/structured.json` | сотрудники, кафедры, направления, новости |
| `backend/data/documents.jsonl` | документы для индекса |
| `backend/data/index/` | фрагменты, векторы и метаданные поиска |

Разбираются отдельными парсерами: дирекция и карточки сотрудников (должность,
кабинет, телефон, почта), кафедры, страницы кафедр, направления подготовки
всех уровней, приёмная комиссия, новости. Остальные страницы попадают в индекс
как текст.

Обновить данные можно и на лету: `POST /api/kb/reindex?scrape=true`.

## Инструменты агента

| Инструмент | Зачем |
|---|---|
| `find_person` | сотрудник по фамилии в любом падеже — кабинет, телефон, почта |
| `search_academy` | гибридный поиск по всей базе знаний |
| `latest_news` | свежие новости и анонсы |
| `list_departments` | кафедры и заведующие |
| `list_programs` | направления подготовки по уровням |
| `open_page` | дозагрузить страницу academy.rudn.ru, если данных не хватает |

Системный промпт требует отвечать коротко (ответ идёт в синтез речи) и
заканчивать ссылкой на источник.

## API

| Метод | Эндпоинт | Назначение |
|---|---|---|
| `GET` | `/api/health` | состояние модели, базы знаний, голоса |
| `POST` | `/api/chat` | ответ потоком (SSE): `token`, `tool`, `done` |
| `POST` | `/api/chat/sync` | ответ целиком |
| `POST` | `/api/voice/ask` | полный цикл: аудио → расшифровка → ответ → mp3 |
| `POST` | `/api/voice/stt` | только расшифровка + разбор обращения |
| `POST` | `/api/voice/tts` | синтез речи |
| `GET` | `/api/kb/search` | прямой поиск по базе |
| `POST` | `/api/kb/reindex` | пересборка индекса (опционально с обходом сайта) |

## Аватар

В `frontend/public/rudik/avatar.svg` лежит векторный Рудик. Чтобы поставить
свой арт, положите файл в `frontend/public/rudik/` и укажите путь в
константе `AVATAR_SRC` в `frontend/src/components/rudik/RudikAvatar.tsx`.

## Настройки

Все параметры бэкенда — через `backend/.env` (см. `.env.example`): модель
Claude и уровень усилий, адреса CORS, задержка обхода, модель эмбеддингов,
голос и модель распознавания.
